Este diretório contém ferramentas externas de uso pessoal:

  Scripts e guias para configurar o Graft + Claude Code em WSL/Ubuntu (`setup-graft.sh`, `README.md`, `CLAUDE.md.exemplo`, `CHECKLISTS.md`).

  Scripts de instalação automatizada para OmniRoute via Docker Compose (`setup-omniroute.sh`, `compose-template.yaml`, `README.md`).

## Uso

Essas ferramentas são **opcionais, não obrigatórias e não versionadas como parte do projeto**. Elas servem para apoiar a produtividade do time de desenvolvimento, mas não alteram regras de negócio, arquitetura ou requisitos do bolão.

- Não incluem dependências no projeto.
- Não devem ser referenciadas por agentes como parte do contexto do produto.
- Mantenha-as fora do versionamento oficial ou marque como untracked conforme decisão do time.
