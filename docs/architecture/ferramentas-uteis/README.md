# Ferramentas Úteis - Bolão Copa FIFA 2027

Este diretório contém scripts, automações e ferramentas auxiliares para facilitar o desenvolvimento, manutenção e operações do projeto **Bolão Copa do Mundo Feminina FIFA 2027**.

## Objetivo

O objetivo desta pasta é centralizar utilitários que não fazem parte do código principal da aplicação (backend/frontend), mas que são essenciais para o dia a dia do desenvolvedor.

## Categorias de Ferramentas

- **Scripts de Dados**: Migrationsções, seed de banco de dados, limpeza ou transformação de dados de teste.
- **Automações**: Scripts para automatizar tarefas repetitivas de ambiente, deploy ou CI/CD.
- **Ferramentas de Teste**: Auxiliares para execução de testes locais ou geração de cenários.
- **Utilitários de Sistema**: Scripts de análise de logs, monitoramento ou verificação de ambiente.

## Como Usar

Cada ferramenta ou script deve conter, idealmente, um pequeno `README.md` ou comentários explicando:
1. Pré-requisitos.
2. Como executar.
3. O que esperar de saída.

---
*Nota: As ferramentas aqui são de uso interno de desenvolvimento e não devem ser enviadas para produção sem validação técnica.*
